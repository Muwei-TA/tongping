# 发布门禁：这是开发首版，不是已上线服务

## 本地演示

可以在本机、虚构数据条件下运行和审阅。默认绑定回环地址。仅演示模式可切换预置身份；不得将该模式公开部署。

## 进入真实小范围试点前

| 门禁 | 当前状态 | 要求 |
| --- | --- | --- |
| 主体、学校与平台准入 | 未核验 | 确定运营主体、学校授权范围、平台类目及必要资质 |
| 微信/QQ 凭据 | 未提供 | 各自 AppID/服务端密钥、合法域名、隐私声明、用户授权与真机测试 |
| 数据治理 | 未完成 | 明确个人信息用途、最少收集、保留期限、导出/删除与备份删除路径 |
| 内容治理 | 未完成 | 人工审核之外的举报、申诉、版权处理、禁用/移除成员、应急响应 |
| HTTPS 与入口保护 | 未部署 | 反向代理限制请求体（建议 8 MB，覆盖 5 MB 图片及 multipart 开销）、连接与速率 |
| 附件边界 | 服务层已限制，入口仍需配置 | Starlette 会先解析 multipart；服务层 5 MB 检查不能代替入口流量/临时磁盘限制 |
| 可用性与灾备 | 仅本地测试 | 单实例真实负载、磁盘监控、权限保护、备份保留与恢复演练 |
| 依赖与密钥 | 版本已固定，未联网扫描 | CI 安装验证、漏洞扫描、密钥管理与日志脱敏 |
| 人工验收 | 待完成 | 产品/技术审阅 PR，逐项完成双端测试，不以源码包生成为上架凭据 |

选择 SQLite 是本版少量社团、单实例假设，不是无限并发承诺。图片也存于数据库，必须监控大小。后续仅在负载或部署要求出现明确缺口时评估 PostgreSQL 和对象存储。

## 明确延期

完整 26 页原型并未逐页产品化；本版按工作流合并为 8 页原生实现。消息推送、收藏/点赞、即时聊天、匿名交友、支付交易、公开展览、视频处理、原帖修订重送审、知识版本、签到学分、邀请深链和跨宿主账号绑定均不在本版实现范围。

帖子与评论目前是人工审核机制，不声称已接入平台文本/图片安全服务。必须把运营主体的实际治理义务与平台要求落实后，才能开放真实发布。

## 回滚

停止写入 → 使用 `scripts/backup.py` 备份并确认可读 → 回退服务代码 → 用对应数据版本进行恢复验证。本版只有初始迁移，不执行自动降级、重建库或清空数据。不能用回退 Git 提交代替数据回滚。
